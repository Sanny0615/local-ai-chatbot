# ⚔️ Shadow AI

A simple local AI chatbot built using Python, Streamlit, Ollama, and Llama 3.2 3B.

## 🚀 Features

- 💬 Chat history
- ⚡ Streaming responses
- 🌡️ Temperature control
- 🧹 Clear chat
- 🎨 Custom dark neon UI
- 🔒 Runs locally

## 🛠️ Tech Stack

- Python
- Streamlit
- Ollama
- Llama 3.2 3B

## 🧠 What I Learned

This project helped me understand how a local LLM application works:

User → Streamlit → Python → Ollama → Llama → Response → User

I also learned about:

- Streamlit session state
- Chat history
- System prompts
- LLM temperature
- Streaming responses
- Connecting Python with a local LLM
